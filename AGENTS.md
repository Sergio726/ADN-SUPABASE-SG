# AGENTS.md — Alambres del Norte

Punto de entrada para agentes y personas que llegan al repo.

## Por dónde empezar

1. **`docs/HANDOFF.md`** — estado, roles y forma de trabajo.
2. **`README.md`** — cómo correr el proyecto y stack.
3. **`docs/PENDIENTES.md`** — qué falta y de quién depende.
4. **`DOCUMENTACION.md`** — detalle técnico (parcialmente desactualizado).

No hay Issues para estas tareas: la fuente de verdad es el checklist. Tildar `[x]`, no reescribir.

Antes de push: `npm run build`.
