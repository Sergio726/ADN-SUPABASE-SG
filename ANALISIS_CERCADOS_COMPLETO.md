## 🧮 3. FÓRMULA DE CÁLCULO

### **Fórmula Principal:**

```
TOTAL = Tejido + Postes + Cordón + Púa + Accesorios + Mano de Obra

Precio por Metro Lineal = TOTAL / Metros_Lineales
```

### **Ejemplo Real (Cerco 2m - Económico):**

```
Tejido:           18 rollos Cal.14 Rombo 3.5" × $65,445     = $1,178,010
Postes:           Eucalipto (completo)                       = $1,110,000
Cordón:           10 cm                                      = $997,920

────────────────────────────────────────────────────────────────────────
TOTAL:                                                       = $8,974,302

Precio por metro: $8,974,302 / 180m = $49,857.23 por metro
```

## 📐 6. CÁLCULO PARA TERRENOS PERSONALIZADOS

### **Método de Cálculo:**

1. **Cliente ingresa:**
   - Largo del terreno (metros)
   - Ancho del terreno (metros)

2. **Sistema calcula:**
   ```
   Perímetro = 2 × (Largo + Ancho)
   ```

3. **Cliente selecciona:**
   - Altura del cerco
   - Tipo de tejido
   - Tipo de postes
   - Cordón (sí/no, tamaño)
   - Hilos de púa (0-4)

4. **Sistema calcula:**
   ```
   - Rollos necesarios = CEIL(Perímetro / 10)
   - Postes necesarios = proporcional a 180m base
   - Materiales = proporcional a 180m base
   - Mano de obra = Perímetro × $11,438
   - Transporte = Perímetro × $3,580.50
   
   Si Perímetro < 50m:
      Total = Total_Base × 1.30
   ```

5. **Sistema genera:**
   - Presupuesto detallado
   - Precio total
   - Precio por metro lineal
   - PDF profesional

### **7.2 Función: Calcular Precio de Cercado**

```sql
CREATE OR REPLACE FUNCTION calcular_precio_cercado(
  p_config_id UUID,
  p_metros_lineales DECIMAL
)
RETURNS TABLE(
  costo_tejido DECIMAL,
  costo_postes DECIMAL,
  costo_cordon DECIMAL,
  costo_pua DECIMAL,
  costo_accesorios DECIMAL,
  costo_mano_obra DECIMAL,
  costo_transporte DECIMAL,
  total DECIMAL,
  precio_por_metro DECIMAL
) AS $$
DECLARE
  v_config RECORD;
  v_factor DECIMAL;
  v_recargo DECIMAL := 1.0;
  v_rollos INTEGER;
  v_precio_tejido DECIMAL;
BEGIN
  -- Obtener configuración
  SELECT * INTO v_config
  FROM configuraciones_cercado
  WHERE id = p_config_id;
  
  -- Factor de proporción vs base de 180m
  v_factor := p_metros_lineales / 180.0;
  
  -- Recargo para terrenos pequeños
  IF p_metros_lineales < 50 THEN
    v_recargo := 1.30;
  END IF;
  
  -- Calcular rollos necesarios (10m por rollo)
  v_rollos := CEIL(p_metros_lineales / 10.0);
  
  -- Obtener precio del tejido
  SELECT precio_venta INTO v_precio_tejido
  FROM tejidos_configuraciones
  WHERE id = v_config.tejido_config_id;
  
  -- Calcular costos
  RETURN QUERY SELECT
    (v_rollos * v_precio_tejido) as costo_tejido,
    (
      (v_config.cantidad_postes_esquineros * v_config.precio_poste_esquinero) +
      (v_config.cantidad_postes_refuerzos * v_config.precio_poste_refuerzo) +
      (v_config.cantidad_postes_intermedios * v_config.precio_poste_intermedio * v_factor) +
      (v_config.cantidad_puntales * v_config.precio_puntal)
    ) as costo_postes,
    (v_config.cordon_precio_total * v_factor) as costo_cordon,
    (p_metros_lineales * v_config.hilos_pua * v_config.precio_pua_por_metro) as costo_pua,
    (v_config.precio_total_accesorios * v_factor) as costo_accesorios,
    (p_metros_lineales * v_config.precio_mano_obra_por_metro) as costo_mano_obra,
    (p_metros_lineales * v_config.precio_transporte_por_metro) as costo_transporte,
    (
      (v_rollos * v_precio_tejido) +
      (v_config.cantidad_postes_esquineros * v_config.precio_poste_esquinero) +
      (v_config.cantidad_postes_refuerzos * v_config.precio_poste_refuerzo) +
      (v_config.cantidad_postes_intermedios * v_config.precio_poste_intermedio * v_factor) +
      (v_config.cantidad_puntales * v_config.precio_puntal) +
      (v_config.cordon_precio_total * v_factor) +
      (p_metros_lineales * v_config.hilos_pua * v_config.precio_pua_por_metro) +
      (v_config.precio_total_accesorios * v_factor) +
      (p_metros_lineales * v_config.precio_mano_obra_por_metro) +
      (p_metros_lineales * v_config.precio_transporte_por_metro)
    ) * v_recargo as total,
    (
      (
        (v_rollos * v_precio_tejido) +
        (v_config.cantidad_postes_esquineros * v_config.precio_poste_esquinero) +
        (v_config.cantidad_postes_refuerzos * v_config.precio_poste_refuerzo) +
        (v_config.cantidad_postes_intermedios * v_config.precio_poste_intermedio * v_factor) +
        (v_config.cantidad_puntales * v_config.precio_puntal) +
        (v_config.cordon_precio_total * v_factor) +
        (p_metros_lineales * v_config.hilos_pua * v_config.precio_pua_por_metro) +
        (v_config.precio_total_accesorios * v_factor) +
        (p_metros_lineales * v_config.precio_mano_obra_por_metro) +
        (p_metros_lineales * v_config.precio_transporte_por_metro)
      ) * v_recargo / p_metros_lineales
    ) as precio_por_metro;
END;
$$ LANGUAGE plpgsql;
```
